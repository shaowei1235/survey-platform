# 主なテスト観点

<span class="status-chip">Testing / Acceptance views</span>

## 認証・認可

| 観点 | 操作 | 期待結果 |
| --- | --- | --- |
| 認証情報の秘匿 | 不正パスワード / 未登録社員番号でログイン | どちらも 401 `INVALID_CREDENTIALS` |
| Refresh rotation | 更新後に古いトークンを再利用 | 拒否される |
| 管理画面の入口 | 従業員ロールだけでアクセス | 管理機能へ入れない |
| 部門越権 | 営業部長が開発部を指定 | 403 `FORBIDDEN_SCOPE` |
| ロール不足 | 従業員が分析 API を呼ぶ | 403 `FORBIDDEN_ROLE` |

## アンケートと回答

| 観点 | 操作 | 期待結果 |
| --- | --- | --- |
| 公開条件 | 回答可能な設問なしで公開 | 400 |
| 定義の不変性 | 公開後に component list を変更 | 409 `SURVEY_NOT_EDITABLE` |
| 削除制約 | 公開中 / 終了済みを削除 | 409 `SURVEY_NOT_DELETABLE` |
| 下書き削除 | 下書きを削除 | 204、関連データも整合 |
| 属性改ざん | body に別の `department_id` を混入 | DB の所属属性を保存 |
| 二重送信 | 同じ利用者が再回答 | 409 `ALREADY_SUBMITTED` |
| 状態制約 | 未公開 / 終了済みに回答 | 409 |

## 集計・匿名化

| 観点 | テストデータ | 期待結果 |
| --- | --- | --- |
| 開示境界 | n=5 | 平均値を表示 |
| 非開示境界 | n=3 | `masked=true`、平均値は `null` |
| 件数の秘匿 | 部門長が n=3 を参照 | n も `null` |
| 未回答 | n=0 | マスクではなく未回答として表示 |
| ロールアップ | 営業部 8 = 課 5 + 3 | 部では開示、課 3 は非開示 |
| フィルタ | 年代・職級を指定 | 回答時点のスナップショットに適用 |
| Excel | 同じ条件で出力 | 画面と同じセルが非開示 |
| 回答状況 | 対象人数が 5 未満 | 回答済・未回答の件数も非開示 |

## AI・自由記述

| 観点 | 条件 | 期待結果 |
| --- | --- | --- |
| 正常分析 | 固定意図と十分な回答 | conclusion と evidence が返る |
| 数値照合 | モデルが異なる平均値を返す | `AI_NUMBER_MISMATCH` |
| 上流障害 | API key なし / 不正 URL | 502 / 503、根拠のない結論なし |
| データ不足 | 開示できる設問が 0 | LLM を呼ばず不足を返す |
| 識別子除去 | メール・電話・社員番号を含む記述 | モデル入力と引用から除去 |
| SSE | ストリーミング API | evidence 構築後に delta、最後に result |
| 要約人数 | モデルが具体人数を生成 | Schema / アプリ検証で拒否 |

## UI・i18n・ログ

- 回答画面に部門・職級・年代の入力欄がない。
- 管理画面と回答画面の可視文言が日本語リソースまたは設問定義に由来する。
- 画面の言語切替はなくても、locale ディレクトリが分離されている。
- ログへパスワード、トークン、自由記述全文、完全な回答 payload を出さない。
- エディタの選択移動は Undo 対象外で、設問変更はキーボード操作で戻せる。

# 画面構成

<span class="status-chip">Design / User flows</span>

## 二つの利用体験

このシステムには、操作目的が異なる二つのフロントエンドがあります。人事・分析ロール向けの管理画面は情報密度を高くし、従業員向けの回答画面は迷いなく回答を完了できることを優先しました。

## 管理画面

| 画面 | 主な利用者 | 役割 |
| --- | --- | --- |
| ホーム | 管理系ロール | 権限に応じた機能への入口 |
| アンケート一覧 | 人事、分析ロール | 下書き・公開中・終了の状態確認 |
| アンケート編集 | 人事 | 部品追加、並べ替え、プロパティ編集、プレビュー |
| 部門・従業員 | 人事、システム管理者 | 組織階層、属性、ロールの保守 |
| 分析ダッシュボード | 人事、経営層、部門長 | クロス集計、回答状況、Excel 出力 |
| 固定分析 | 人事、経営層、部門長 | 低得点項目と原因を evidence 付きで確認 |

### アンケート編集

エディタは「部品パレット・キャンバス・プロパティ」の 3 カラム構成です。クリックまたはドラッグで設問を追加し、キャンバスで並べ替え、右側で必須・選択肢・得点設定を編集します。Undo / Redo は設問変更だけを対象とし、選択状態は履歴へ入れません。

### 分析ダッシュボード

アンケート、部門、年代、職級を選択し、部門別の平均点をグラフと表で確認します。少人数セルは「非開示（n&lt;5）」、回答 0 件は「まだ回答がありません」と区別します。

## 回答画面

| 画面 | 目的 | 重要な制約 |
| --- | --- | --- |
| ログイン | 回答者を識別 | 管理画面と同じアカウント体系 |
| 回答可能一覧 | 未回答かつ公開中の調査を表示 | 回答済み・終了済みは表示しない |
| 回答 | 設問の表示と入力 | 部門・職級・年代の編集欄を持たない |
| 完了 | 送信完了を通知 | 個人回答や集計結果を表示しない |

## ロール別の表示と API 権限

| 操作 | 人事 | 経営層 | 部門長 | 従業員 |
| --- | --- | --- | --- | --- |
| アンケート作成・公開 | 可 | 不可 | 不可 | 不可 |
| 組織マスタ変更 | 可 | 不可 | 不可 | 不可 |
| 全社分析 | 可 | 読み取り | 不可 | 不可 |
| 自部門分析 | 可 | 読み取り | 読み取り | 不可 |
| 回答 | 対象外 | 対象外 | 対象外 | 可 |

ボタンの非表示や無効化は操作ミスを減らすための UI 制御です。最終的な権限判定は必ず API 側で行います。

## 代表的な操作フロー

<ol class="journey">
  <li>人事が下書きを作る</li>
  <li>設問を編集・保存</li>
  <li>アンケートを公開</li>
  <li>従業員が一度だけ回答</li>
  <li>権限内で集計を確認</li>
  <li>終了して回答を締切</li>
</ol>
